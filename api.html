API · v1 · proposal §7.2

A scenario API with no server.

The proposal's API contracts run inside your browser. A service worker intercepts requests to api/v1/…, runs the same engine as the workspace on the bundled data, and stores scenarios in IndexedDB. Identical inputs on the same data build return the same scenario_id.

PM E-DRIVE and Unified Bharat E-Charge

Scenarios use PM E-DRIVE costing by default. Add "pm_edrive": {"budget_basis": "subsidy", "prefer_swap": false, "cap_category_a": true} to the request to choose what the budget counts. Each selected site then returns its location category (A–D), station configuration with connector standards, upstream and EVSE costs, subsidy split and net cost; the scenario returns an Annexure-B style summary and the optimiser's approximation guarantee.

MHI's guidelines require implementing agencies to share charger location, availability, pricing and payment options with the National Unified Hub, Unified Bharat E-Charge, built by BHEL (Step 3(iii), FAQ 12). Its data protocol is not yet published. GET /scenarios/{id}/ubec therefore produces a draft in a neutral, OCPI-aligned shape: stations start as PLANNED, pricing and payment options are left for the operator, and each connector carries its BIS standard and the OCPI 2.2.1 code where one exists. The same service can sit behind a ULB or state planning portal: it is a stateless HTTP service with API keys, an OpenAPI 3.1 description and reproducible scenario ids.

From your own page

const res = await fetch("api/v1/scenarios", {
  method: "POST", headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    geography_id: "maharashtra.pune", objective_profile: "coverage",
    threshold_km: 10, budget_lakh: 500, distance_metric: "straight",
    cost_model: { hardware: "dc60" }, include_sensitivity: true
  })
});
const scenario = await res.json();   // 201 Created, Location: api/v1/scenarios/{id}

Limits: a service worker answers requests from pages on this site's origin (after its first load). Tools outside the browser such as curl can't reach it; the same engine runs in Node (see tests/) for server-side use.
